# Self-Modifying Mini-Language — Near NASA-Grade

This bundle adds: tests, static analysis, deterministic evolution, audit logging, resource contracts, optional HMAC integrity, and a spec skeleton.

## Quickstart
```bash
python -m mini_lang.interpreter_secure
```

## Deterministic Mode
Pass `deterministic_seed=42` to `Interpreter`/`RealTimeInterpreter` for reproducible evolution.

## Static Analysis
Wire with:
```python
from mini_lang.static_analyzer import analyze_ast
interp = Interpreter(src_lines, static_analyzer=analyze_ast)
```

## Audit
`AuditLogger.dump_json(path)` to export structured trace.
